Chromosome/chromatin tracing 

Code to perform chromatin tracing image analysis in Ntemos et al. 2025 (doi: https://doi.org/10.1101/2025.10.22.684035). Refer to the Methods section for additional details.

Data:
Chromosome tracing coordinates can be found in the Supplementary Data for Ntemos et al. 

System Requirements and Installation:
MATLAB (v2024b) or later, some scripts require the Image Processing Toolbox and the Statistics and Machine Learning Toolbox. See mathworks.com for installation.  
Unless otherwise noted below, all scripts can be run interactively in <1h on an HPC cluster with 4 cores and 26GB RAM requested.
