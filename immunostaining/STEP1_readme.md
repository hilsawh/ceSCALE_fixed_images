STEP 1 of pre-processing: ND2 to MAT converter

Converts image stacks from a Nikon .nd2 file into one .mat file per channel per FOV, written to “hyb0\_channels/”

&nbsp;

**Runtime and resources:**

- This was run in an Open OnDemand MATLAB session on Trillium with 16 cores and 120 GB of memory requested.  
- dataset\_2: 1 imaging field of view with three channels (3 files of 522 MB each, 1608x1608x101) took about 20 seconds.  
- dataset\_3: 1 imaging field of view with three channels (3 files of 1.22 GB each, 1608x1608x235) took about 40 seconds.

&nbsp;

**convertnd2.m** is the script you run and edit from MATLAB. It holds the Python code as text, fills in your settings, writes **convert\_nd2\_v2.py** to MATLAB's current folder, and runs it under a module-loaded Python.

**convert\_nd2\_v2.py** is generated by **convertnd2.m** every time you run it. Do not edit it; changes are overwritten.

&nbsp;

Output:

Files are written to "WORKDIR/hyb0\_channels/" and named Prefix\_0\_FOV.mat, for example DAPI\_0\_6.mat. The FOV number is the FOV's position in the ND2 file

Each channel is matched by the wavelength in its name and gets its own file. The 405 channel is saved as DAPI\_0\_FOV.mat with the variable ImageStackDAPI. The 488 channel is saved as Lineage\_0\_FOV.mat with the variable ImageStackLineage. The 561, 640 or 647 channel is saved as PGranule\_0\_FOV.mat with the variable ImageStackPGranule.

Running FOVS \= \[6\] gives you three files in hyb0\_channels/: DAPI\_0\_6.mat, Lineage\_0\_6.mat and PGranule\_0\_6.mat.
