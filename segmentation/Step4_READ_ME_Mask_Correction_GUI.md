# Purpose of Code
After running Cellpose-SAM to generate nuclei masks for all embryos they have imaged, the user loads the raw images, the masks, the PG channel (optional), and the lineage fluorescence channel (optional) into the napari GUI. They can then make manual adjustments to their masks including splitting undersegmented masks, deleting masks, merging oversegmented masks, and creating new masks for missed nuclei. The GUI also performs automatic detection of the P-cells and the fluorescent lineage cells and allows the user to perform an easy adjustment in the case of error. Once the user is finished they save the adjusted masks and 2 CSV files with the mask IDs for the P-cells and lineage cells (optional). The user is then ready to calculate Nstats in MATLAB and run CeSCALE to determine cell identity. 

# How to use Code
### Folder Loading
The user must use the "Select image folder" and the "Select mask folder" buttons to choose the folder location of their tiff images and tiff mask files outputted by cellpose respectively. Optionally the user can also use the "Select PG folder" and the "Select lineage fluorescence folder" to load in tiff files for these channels. These optional channels will be used to output a csv file with the mask ID for P-cells and fluorescently labeled cells. Files are matched across channels using extracted (sample number, FOV number) pairs.
### Image Navigation
The user can toggle through embryo images in their selected folders using the "Next image" and "Previous image" buttons. The user can also switch their view from 3D to 2D and back using the "Switch to 2D"/"Switch to 3D" button.
### P-Cell Selection
If the PG folder has been selected, upon loading a new Embryo N P-cells will automatically be detected where N is the integer in the "Number of P-cells" textbox. The user can change this integer in the textbox and press enter to redo the automatic selection of P-cells. The user can also manually add or remove P-cells by clicking on masks to select them and using the "Add selected to P-cell mask" or "Remove selected from P-cell mask" buttons.
### Lineage Cell Selection
Similar to the P-cell selection methodology, upon loading a new embryo N lineage cells will automatically be detected where N is the integer in the "Number of lineage cells" textbox. The user can change the integer in the textbox and press enter to rerun automatic detection or manually add or remove cells from the lineage mask in the exact same way as is done for the P-cells.
### Selection Buttons
The user selects masks by clicking on them in the image. The user can select a mask with a particular label ID by typing the integer ID in the "Find mask label" textbox and pressing enter. The user can also clear all selected masks by pressing the "Clear selected masks" button. Additionally the user can view main image signal contained specifically within the currently selected masks by clicking the "Show selected signal" button. They can then revert to showing all signal by clicking the same button now named "Show full signal". 
### Seed Points
The user can select the "Enable point selection" button to turn on seed points. Then click anywhere within the image to add seed points. It is highly recommended to enter 2D viewing mode when selecting seed points to allow for high precision. Seed points can be placed outside of masks in order to perform watershed around the point to create a new mask. Multiple seed points can be placed within an existing mask to perform watershed where the mask is split into several masks (1 per seed point placed). The user can click the "Clear points" button to remove current seed points. 
### Watershed (split one mask)
The user should select exactly one mask they want to split into multiple masks. Then the user can allow for automatic seed point selection for the watershed algorithm by not placing seed points within the mask. In this case the number of masks created will be dictated by the textbox "Number of Masks" and the minimum distance in pixels between automatically detected seed points will be the integer in the "Min Distance" textbox. Alternatively they can place seed points within the selected mask using the instructions above. In either case when ready the user must select "Watershed selected mask". Then the user will be able to inspect the split mask in the watershed channel. If the user is happy with the watershed split they can select "Confirm watershed/new nuclei" to save this watershed result into their primary mask channel. If unhappy with the watershed result the user can change the location of seed points or the automatic seed point parameters and run the algorithm again. Note that sometimes when the "Min Distance" value is too high the automatic seed point detection can not find enough seed points far enough apart to create the desired number of masks. In this case you will have to lower the "Min Distance" or the "Number of Masks".
### Add new nuclei (from seed points)
The user must first place 1 or more seed points outside of existing masks in the center of the region where they would like to create a new mask (use seed point placement instructions above). They then must set the area in which watershed is allowed to occur using the "Max Radius" of the mask from a seed point textbox and the "Missing Mask Threshold" textbox which sets the minimum intensity a pixel in the image must be to be included in a new mask. They then can click "New nuclei watershed" and the new nuclei masks will be created in the "new nuclei" channel. Similar to the watershed splitting algorithm above the user can inspect the newly created mask(s) and decide if they are happy with them. If they are they can click "Confirm watershed/new nuclei" to add these mask(s) to the primary mask channel. Alternatively the user can adjust the seed points or parameters and rerun the "New nuclei watershed" by clicking the button again.
### General Mask Editing and Saving Annotations
The user can click the "Delete selected masks" button to remove any selected masks. The user can click the "Merge selected masks" button to combine multiple selected masks into a single mask. The user can click "Smooth all masks" to apply a size neutral smoothing algorithm to all masks thereby decreasing jaggedness. The user can change the value in the "Minimum mask size" textbox and then click "Delete small masks" to remove all masks below a certain voxel count. The user can change the value in the "Pixel Dialation" textbox and then click "Dialate" to dilate all selected masks by a certain number of pixels. The user can also click the "Undo" button to revert to the previous state (maximum of 10 previous states stored). Finally when the user is happy with all the changes they have made they can click "Save current mask". This will save the adjusted mask as a Tiff file in a newly created "Adjusted_Masks" folder within the same parent directory as the Mask folder previously selected by the user. Additionally, the mask ID associated with P-cells and lineage cells will be saved within respective CSVs in the same "Adjusted_Masks" folder.
### Adjusting Visible layers
On the left hand side of the napari GUI is a list of layers including at minimum the "image" and the "mask". It is highly recommended that the user toggles the visibility of these layers when manually adjusting the masks using the GUI.   

# Key Algorithm Explanations
### Watershed Based Demerging of Undersegmented Masks
If the user has manually placed seed points within the selected mask to be demerged these are used as the seed points. Otherwise seed points are automatically detected by selecting the N points (N is user inputted) that are the maximum distance from the edge of the binary mask and at least "Min Distance" apart (user inputted). Then using the manually inputted or automatically detected seed points an inverse distance watershed algorithm is performed to split the mask.

### Adding a Missed Mask
The user must manually place at least one seed point outside an existing mask in the center of the region that will become the new mask. The allowable watershed area is then set by the "Max Radius" (user inputted) and "Missing Mask Threshold" (user inputted). A pixel within the allowable watershed area will be at most "Max Radius" away from a seed point and at least the image intensity of the "Missing Mask Threshold". Then an inverse distance watershed is performed to split this allowable area between the manually selected seed points.

### Automatic Detection of P-Cells
First the PG channel is filtered such that any pixel below the 95th percentile of intensity is set to 0. Then the average PG channel intensity per mask area is calculated for all masks. Then the top 5 masks in this metric are selected and dilated 5 pixels each. Then the average PG channel intensity is recalculated and the top N (user inputted) masks are selected as the nuclei of the P-cells. Dilation of the masks is important because P-granules are not nuclearly localized and often sit just outside the nuclei masks.

### Automatic Detection of Lineage Cells
First the 90th percentile of the lineage channel within all masks is calculated. Then the percentage of voxels within each mask above this threshold is calculated. The top N (user inputted) masks with the highest percentage of voxels above the threshold are determined to be the nuclei of the fluorescently labeled lineage cells.
