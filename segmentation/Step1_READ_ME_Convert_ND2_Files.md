# Purpose of Code
This MATLAB script is used to extract all channels from the Hyb 0 ND2 file, all of the normal Hyb round ND2 files (if available), and the territory ND2 files (if available) to convert them to .mat files. The user must adjust the folder path containing the ND2 files as well as the channels present and their order (detailed below). The .mat image files produced during this step are used in the upcoming MATLAB script in order to create the TIFFs necessary for Cellpose. This step should be run on the cluster as it uses a lot of memory to open large ND2 files. 

# How to Run Code
1. Set the variable "nd2Folder" to be equal to your directory containing all the ND2 files.
2. Change the number of "territoryRounds" based on the number of ND2 files you have for territory probes. If you have no territory ND2 files then set this value to 0. Additionally, change "territoryPosition" to "End" or "Before" depending if the territory probes were taken before or after the Hyb rounds (excluding Hyb0 which is assumed to have been done first).
3. Change the hyb0ChannelCount and the ordering of the Hyb0 channels based on how they were imaged and stored in the ND2 file. If a specific channel is not present set its value to []. By default if both SD (spinning disc) and WF (wide field) DAPI channel was imaged then SD will be used going forward.
4. Change the number and order of channels used for later rounds (normal non-0 Hyb rounds and territory rounds). If you do not have these rounds you can ignore these values as they will not be used.

Note: ND2 files within the directory are assumed to be in alphabetical order with Hyb0 being alphabetically first. It is then assumed that successive Hyb rounds and territory rounds are alphabetically organized with either all Hyb rounds first or all territory rounds first. Additionally, it is required to have the "bfmatlab_5.9.2" folder added to path in MATLAB to run this code, see https://docs.openmicroscopy.org/bio-formats/5.9.2/users/matlab/index.html.
